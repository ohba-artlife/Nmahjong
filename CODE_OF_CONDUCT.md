# Code of Conduct

This project is a place to make a correct, checkable description of mahjong. Everyone who takes part — in issues, pull requests and reviews — is asked to follow this code.

## What we ask

- Be respectful. Disagree with the statement, not with the person.
- Give reasons and sources. Mahjong rules differ by place and by group; "our rule is different" is useful information, not an error on someone's part.
- Assume good faith, and accept correction when a source shows you were wrong.
- Write so that newcomers and non-native readers can follow.

## What is not accepted

- Insults, harassment, or discrimination of any kind.
- Publishing someone else's private information (names, addresses, accounts, game logs that identify a person).
- Repeatedly taking a discussion away from its subject.
- Promotion of gambling services, or solicitation.

## Scope

This code applies to all spaces of this project (the repository, its issues and pull requests) and to anyone acting on behalf of the project elsewhere.

## Reporting and enforcement

Report a problem to the maintainer (**ohba-artlife**) through GitHub: use "Report content" on the comment or issue in question. Reports are handled confidentially.
The maintainer may edit or remove comments, close or lock threads, and block accounts that do not follow this code.
